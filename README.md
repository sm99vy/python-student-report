# 🎓 Sistema de Boletim Escolar em Python

Programa desenvolvido em Python para registrar alunos, armazenar suas notas e consultar informações de desempenho acadêmico.

## Funcionalidades

- Cadastro de alunos
- Registro de notas
- Armazenamento dos dados em listas compostas
- Consulta das informações cadastradas
- Exibição do desempenho dos alunos

## Tecnologias

- Python 3

## Conceitos praticados

- Listas compostas
- Estruturas condicionais
- Laços de repetição
- Organização de dados
- Consulta e análise de informações

## Como executar

```bash
python student-report.py
```

## Objetivo

Praticar a criação de uma estrutura simples de gerenciamento de informações, utilizando listas compostas para organizar dados acadêmicos.
